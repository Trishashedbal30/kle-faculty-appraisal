# Course Project Submission Scaffold

This folder is a structure-only scaffold for course materials that have not yet been supplied. It does not contain the original course problem statement, a final project report, or completed assignment submissions.

## Submission contents

- [Assignments 01–12](./Assignments/README.md): numbered placeholders awaiting the original assignment files and descriptions.
- [Original problem statement placeholder](./Documentation/Original%20Problem%20Statement.md): the original document has not been provided.
- [Final course project report placeholder](./Documentation/Final%20Course%20Project%20Report.md): the report has not been provided.
- [Source code location](./Source%20Code/README.md): application source remains in the repository root to preserve its existing layout and startup commands.

Do not treat this scaffold as a complete academic submission. Replace or supplement these placeholders only with the course documents and verified student/course details provided by the project team.
